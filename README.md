# anime-hub
Trabalho de Conclusão da Disciplina de Desenvolvimento em Ambiente Web.

# Autora
Heloiza Brasil.

# Fase 1
Entrega dos wireframes mobile, tablet, desktop.

# Fase 2
Construção da página no App.tsx com React, TypeScript e CSS, seguindo os wireframes (mobile, tablet e desktop).

# Fase 3
Separação da página em componentes, listagens com map e key, e interações com useState: favoritar animes, aba Favoritos que filtra a lista e modo escuro.

# Fase 4
Listagem principal carregada com fetch e useEffect, com estados de carregando e de erro.

# Como executar
```bash
npm install
npm run dev
```

# Fonte dos dados
A listagem principal vem do arquivo public/animes.json, carregado com fetch. A listagem de gêneros e o destaque vêm de vetores locais em src/data.
